Throughput

The store keeps no record of finished jobs. Completed is derived from the identity pending_now = pending_prev + arrivals − departures, taking arrivals as the rows whose ZTIMESTAMP falls inside the interval. It is an inference, not a counter Photos maintains.

Assets with the most work queued

§19 records that this table has "no asset reference" — true of its columns, but ZIDENTIFIER holds an asset UUID for most rows, so the queue is in practice attributable. Rows whose identifier is a literal or a JSON blob are marked not an asset.

Job mix by ZJOBTYPE / ZJOBFLAGS

ZJOBFLAGS is a bitmask — every observed value decomposes into powers of two — so the bits are shown rather than named: the meaning of individual job types and flags is not established, and guessing would be worse than saying so.

Database table census and the counter check that integrity_check cannot do

Table census largest 60 tables

Primary-key counters

Core Data allocates every primary key from Z_PRIMARYKEY.Z_MAX + 1. A table whose highest row exceeds its counter means the next save collides, and every edit in the library then fails silently — not just the rows that were written. PRAGMA integrity_check returns ok in this state, so this is the only check that catches it (§3.2, §20.2).

Reference what the background workers do, and what the numbers mean

Background workers

These names are read from the Objective-C class list of Apple's PhotoLibraryServices framework, so they are real. Which worker a given ZJOBTYPE number routes to is not established, so this is a catalogue of the work Photos does — not a decoder for the numbers in the job mix table.

Codes seen in this library

ZJOBTYPE 11
Cascade donation. Every row of this type carries the literal identifier PLCascadeDonationRequired, which names PLBackgroundJobCascadeDonationWorker — donation is how Photos hands content to Spotlight. The one job type whose meaning is settled by direct evidence.
ZJOBTYPE 2
Mixed. Mostly per-asset, but some identifiers are JSON objects such as {"type":1700,"label":"Schueberfouer"} naming a place, event or category. Those inner numbers are not album kinds — only 2 of the 8 observed exist in ZGENERICALBUM.ZKIND, and those albums have no title — so they are a separate taxonomy of unknown meaning.
ZJOBFLAGS
A bitmask. Every observed value decomposes into powers of two (3 = 1|2, 14 = 2|4|8, 1026 = 2|1024), so the individual bits are shown. What each bit means is not established.
Scheduler verdicts
CP Can Proceed · MNP May Not Proceed · AMNP Absolutely May Not Proceed. The policy that usually blocks work is Device Activity, which refuses to run while the Mac is in use.
Search categories
1200 your keywords · 1500 / 1501 Apple's scene labels, singular and plural. Other category numbers are not established.
ZLOCALAVAILABILITY
1 the file is on this Mac · −1 it is not (iCloud only).
ZBUNDLESCOPE
0 your own library · 2 an iCloud Shared Album asset, which has no file on disk.
Latitude −180.0
Not a real coordinate: it is the sentinel Photos stores for no location, in place of NULL.
